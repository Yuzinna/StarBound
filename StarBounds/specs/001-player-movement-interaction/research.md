# Research: 플레이어 이동 및 상호작용

## 1. 테스트 프레임워크 선정

-   **Decision**: `Unity Test Framework`를 사용합니다.
-   **Rationale**: Unity에 내장된 공식 테스트 프레임워크로, 별도의 외부 도구 설정 없이 즉시 사용할 수 있습니다. Play Mode 테스트를 지원하여 실제 게임 환경과 유사한 조건에서 플레이어의 움직임 및 상호작용을 테스트하기에 가장 적합합니다. Edit Mode 테스트 또한 지원하여 순수 로직 검증도 가능합니다.
-   **Alternatives considered**: NUnit, xUnit 등 외부 프레임워크를 고려했으나, Unity 에디터와의 통합 및 Play Mode 테스트의 편의성 측면에서 Unity Test Framework가 압도적으로 유리합니다.

## 2. 타겟 플랫폼 결정

-   **Decision**: 초기 개발 단계에서는 `PC (Windows, Mac, Linux)`를 주 타겟 플랫폼으로 설정합니다.
-   **Rationale**: PC 플랫폼은 개발 및 테스트가 가장 용이하며, 대부분의 개발자가 접근 가능한 환경입니다. 키보드 입력 기반의 조작계를 우선 구현하는 현 단계에 가장 적합합니다. 추후 다른 플랫폼(모바일, 콘솔 등)으로의 확장을 고려할 수 있으나, 초기에는 PC에 집중하여 핵심 게임플레이를 완성하는 것이 효율적입니다.
-   **Alternatives considered**: 모바일 플랫폼을 고려했으나, 터치스크린 입력 처리를 위한 추가 개발이 필요하며, 현재 명세는 키보드 입력을 전제로 하므로 초기 단계에서는 제외했습니다.
