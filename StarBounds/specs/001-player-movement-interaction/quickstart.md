# Quickstart: 플레이어 이동 및 상호작용

이 문서는 '플레이어 이동 및 상호작용' 기능이 구현된 후, 이를 빠르게 테스트하고 검증하는 방법을 안내합니다.

## 사전 준비

1.  Unity Hub를 통해 이 프로젝트를 엽니다.
2.  `001-player-movement-interaction` 브랜치가 체크아웃 되어 있는지 확인합니다.
3.  Unity 에디터에서 테스트용 씬(Scene)을 엽니다. (예: `Assets/Scenes/Test/PlayerMovementTestScene.unity`)

## 테스트 절차

### 1. 기본 이동 및 점프 테스트

1.  Unity 에디터 상단의 **Play** 버튼을 눌러 게임을 실행합니다.
2.  **'A'** 키를 눌러 캐릭터가 왼쪽으로 움직이는지 확인합니다.
3.  **'D'** 키를 눌러 캐릭터가 오른쪽으로 움직이는지 확인합니다.
4.  **'스페이스바'** 또는 **'W'** 키를 눌러 캐릭터가 점프하는지 확인합니다.
5.  점프 중 공중에서 'A', 'D' 키를 눌러 약간의 움직임 제어가 가능한지 확인합니다.

### 2. 상호작용 테스트

1.  게임 내에 배치된 **중력 조절 스위치**로 이동합니다.
2.  스위치 근처에서 **'Shift'** 키를 눌러 스위치가 활성화/비활성화되고, 그에 따라 중력이 변하는지 확인합니다. (예: 캐릭터나 다른 오브젝트가 다른 방향으로 떨어짐)
3.  게임 내에 배치된 **큐브 오브젝트**로 이동합니다.
4.  **중력 조절 스위치가 비활성화된 상태**에서 큐브 근처에서 'Shift' 키를 눌렀을 때 아무 변화가 없는지 확인합니다.
5.  **중력 조절 스위치를 활성화한 상태**에서 큐브 근처로 이동합니다.
6.  'Shift' 키를 누른 상태에서 'A' 또는 'D' 키를 눌러 큐브를 좌우로 밀거나 당길 수 있는지 확인합니다.

## Play Mode 자동 테스트 실행

1.  Unity 에디터 상단 메뉴에서 `Window` > `General` > `Test Runner`를 엽니다.
2.  `Test Runner` 창에서 `PlayMode` 탭을 선택합니다.
3.  `Run All` 버튼을 클릭하여 `PlayerMovementTests.cs`에 작성된 모든 자동 테스트를 실행하고, 모든 테스트가 통과하는지 확인합니다.
